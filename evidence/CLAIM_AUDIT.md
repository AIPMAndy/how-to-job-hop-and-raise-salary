# 公开内容证据对抗式审计（2026-10-12）

## 最危险的 10 种伪证据与处理原则

| 攻击/反例 | 修复动作 |
|---|---|
| 拿国外样本说明中国求职/晋升成功率 | 明确地区与场景；保留仅“可参考”的建议 |
| 把相对提升8%写成提升8个百分点 | 写明是相对效果；注明实验平台与样本 |
| 用平均工资当作岗位中位数或 offer 薪资 | 附国家统计局原始定义，另做同城岗位样本 |
| 把高级产品经理头衔等于高管 | 逐项检查团队人数、预算权限、组织层级 |
| 展示模拟案例却称成功客户 | 所有模拟必须写“虚构教学案例”，真正客户需明确授权 |
| 把单个官方JD作为全行业必备硬门槛 | 注明单样本、地点、职位ID与核验日期 |
| 原始文章被转载后链接失效 | 链接指向原始作者/雇主官网，定期检查并标明核验日期 |
| 法律建议用“一定有效/无效/赔偿多少” | 引法条和最新司法解释，提醒按个案核验 |
| 伪造截图、工资流水、Offer 和高管成就 | 不做；只展示公开JD、统计和脱敏授权材料 |
| 资料引用堆在附录、正文不给 | 正文在相应章节显示发现—范围—行动—限制—原始链接 |

## 当前留存缺口（不得假称已验证）

1. **真实中国企业经理晋升案例**：缺少可公开、已授权、具备晋升前后岗位与责任证据的案例；暂用研究和官方招聘样本，避免使用虚构获客故事。
2. **真实中国用户谈薪成交数据**：没有受访同意和完整背景，不能给出“跟做就涨薪X%”。
3. **同城同岗30条最新薪酬JD**：现有官方JD是岗位职责证据，未整理成具有工资范围的30条样本；模板提供采集方法，但不虚构数据。
4. **最近一个月相关职位招聘状态**：公开岗位可能随时下架，使用者必须在点击时再核实。

## 合规案例征集SOP

候选人授权范围明确；仅收集必要岗位/行业/层级/行动前后责任变化；核验能脱敏展示的可追踪记录；让候选人审核摘要、删除可识别信息；未经书面授权不可公开个人经历或合同截图。拒绝“保晋升”“保Offer”“保涨薪”宣传。
