# 第00章 · 三分钟判断现在该不该跳

跳槽可能提高现金收入，也会带来试用期、稳定性、通勤和福利的不确定性。先看约束。

> 读法：每步有具体操作、完成凭证、卡住怎么办。敏感资料只留在本人私有目录。

## 1. 写清跳槽主目标

**具体操作：** 只选一个最高优先目标：现金收入、成长空间、管理职级、城市、稳定性或工作强度。

**完成凭证：** 排序前三的目标与不可接受底线。

**卡住怎么办：** 目标矛盾时确定哪个必须满足，哪个可以牺牲。

- [ ] 完成并留存合规凭证

## 2. 算出真实最低可接受价

**具体操作：** 填当前固定年现金、确定奖金、可变奖金、福利差异与生活成本，分别列“保底”和“可能获得”。

**完成凭证：** 一张同口径年度报酬表。

**卡住怎么办：** 历史奖金不保证未来发放，单独标注。

- [ ] 完成并留存合规凭证

## 3. 检查家庭风险缓冲

**具体操作：** 估算未来3~6个月必要支出与是否能承担试用期风险；不要把未来奖金当现有现金。

**完成凭证：** 风险缓冲表与最差情景。

**卡住怎么办：** 现金不足时优先在职找工作，不主动裸辞。

- [ ] 完成并留存合规凭证

## 4. 确认离职约束

**具体操作：** 查看自己的劳动合同、保密义务、合法适用的竞业限制、未归属股权和奖金约定。

**完成凭证：** 需向HR/合规或专业人士核实的条目清单。

**卡住怎么办：** 条款有争议时咨询专业人士，不凭网上模板断言有效性。

- [ ] 完成并留存合规凭证

## 5. 制定求职节奏

**具体操作：** 每周固定市场研究、岗位匹配、投递、联系、面试复盘四类时间块。

**完成凭证：** 一份未来四周日程计划。

**卡住怎么办：** 工作繁忙就压缩投递量，保证岗位质量。

- [ ] 完成并留存合规凭证


## 深入实操：先算“现在跳槽的真实成本”

在纸上写出三类数字：**当前年度保底税前现金**、当前可能但不保证获得的奖金/股权、离开将损失或产生的成本。再写三条红线：最低现金、通勤与工作时间、城市与家庭约束。没有明确目标时，不要用“同事都跳了”当理由。

**虚构案例**：A每月固定2.5万元、12个月发薪，确定性年现金30万元；还有预期奖金5万元但无保证。新工作固定2.8万元、12个月，保底33.6万元；如果通勤和房租每年新增4万元，现金收入增加的3.6万元已不足覆盖这些额外成本。实际还要考虑税费、社保缴费、时间价值和签字费条件。

**最差情景**：入职日期推迟、背调没过、试用期发生变化、签字费需返还。对每种情况写“触发信号、损失、应对方式”，不把口头Offer当既成事实。

**今日执行**：用表格记录5项薪酬构成；列3条最不能退让的条件；决定“立即投递/先做市场调查/暂缓跳槽”。若收入已中断且资金紧张，先用失业自救指南核对基本保障。

**本章验收**：两份年度报酬比较草稿、风险清单、明确行动选择。

## 真实研究与招聘证据（原始出处，可直接核验）

这些资料解释为什么要执行本章任务；不能保证读者个人晋升或取得 Offer。

### 证据 S01 · 国家统计局2025年城镇单位平均工资（2026-05-15）

**来源级别：** 国家官方统计。**样本/范围：** 全国城镇法人单位及规模以上企业，按官方定义统计。

**真实观察：** 2025年非私营单位平均129441元、私营71590元；信息软件服务非私营单位248752元。

**外推限制：** 各组定义不同，均值不是个体招聘薪酬报价、也不是薪酬中位数；需按地区企业岗位重采样。

**本章落地动作：** 采样30个同城同岗有效JD，单独标出企业工资统计作宏观背景。

### 证据 S05 · 薪资历史披露对招聘者决策的影响（NBER 29460）

**来源级别：** 随机审计实验。**样本/范围：** 数百名招聘人员与2000多份求职申请的实验。

**真实观察：** 薪资历史披露和拒绝披露可能影响招聘者判断，信号解释复杂。

**外推限制：** 实验场景受国家和雇主影响；不能总结为“绝不报现薪”或“报高就好”。

**本章落地动作：** 如实处理合法核验，把沟通聚焦岗位责任和市场数据。
