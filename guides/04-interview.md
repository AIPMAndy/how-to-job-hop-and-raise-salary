# 第04章 · 面试：从复述经历到业务决策

面试评估通常围绕岗位能力、证据可信度和协作方式。

> 读法：每步有具体操作、完成凭证、卡住怎么办。敏感资料只留在本人私有目录。

## 1. 准备8个STAR故事

**具体操作：** 覆盖挑战、增长、降本、冲突、失败、技术决策、跨团队、学习，并注明自己的责任边界。

**完成凭证：** 8张按岗位要求匹配的故事卡。

**卡住怎么办：** 没有某类经历就如实说明相近案例和学习计划。

- [ ] 完成并留存合规凭证

## 2. 准备岗位专业题

**具体操作：** 从目标JD各整理5道技能题和3道综合判断题，按事实、分析、行动写答案。

**完成凭证：** 至少16道题与可信的回答提纲。

**卡住怎么办：** 遇到真实未知问题应说明思路和核验步骤。

- [ ] 完成并留存合规凭证

## 3. 执行两次模拟面试

**具体操作：** 分别做专业面与业务/管理面，录音须征得参与者同意；复盘逻辑和口头表达。

**完成凭证：** 两轮评分表和三个修复动作。

**卡住怎么办：** 无人陪练时自己录音，评估结构而不是猜测招聘官意图。

- [ ] 完成并留存合规凭证

## 4. 面试中问关键问题

**具体操作：** 确认岗位目标、汇报线、团队变动、试用期标准、出差强度、预算与未来半年重点。

**完成凭证：** 每场面试的反向提问记录。

**卡住怎么办：** 招聘方暂时回答不了就标“待确认”。

- [ ] 完成并留存合规凭证

## 5. 面后24小时复盘

**具体操作：** 区分问到什么、答得怎样、有无客观证据、下一轮要修正什么，不做情绪化自责。

**完成凭证：** 面试复盘与下一步练习题。

**卡住怎么办：** 若陷入连续低质量面试，暂停一周重做岗位筛选。

- [ ] 完成并留存合规凭证


## 深入实操：让每道题都能被追问

为目标岗位建立 **8张STAR故事卡**：项目背景、你的职责、关键动作、数据结果、错误与复盘。不是机械背稿；面试官重点核对证据可信度、能力是否适用于岗位。准备2张失败案例，说明当时的约束、错误判断与后续改变。

**典型追问练习**：为什么选这个方案？谁不同意？你本人做了什么？结果有多大外部影响？怎样证明是你推动？重来一次会怎么办？每题先给30秒答案，再准备2分钟深挖。没有数字时描述质量/交付结果，但不要捏造百分比。

**模拟面试三轮**：首轮能力覆盖，次轮反例质询，第三轮高压追问与反向尽调。每次录音录像必须征得参与者许可；不私自录制真实面试、不上传含他人隐私的文件。

**面试结束的反问**：这个岗位入职90天最重要的交付是什么？当前团队最大难题？用什么指标判断试用期成功？下一轮评估能力有哪些？反问不是套话，应帮助你判断是否真的适合。

**本章验收**：8张案例卡、2轮复盘、目标岗位高频题与追问清单。

**额外测试**：若面试官用“结果是不是你个人主导的”追问，就主动说明团队负责范围和你实际决策部分，避免在紧张时冒领团队成果。

### 证据 S06 · 结构化招聘面试研究综述（Campion等，1997）

**来源级别：** 文献综述。**样本/范围：** 回顾面试结构化研究，提出15类结构要素。

**真实观察：** 结构化问题与统一评价标准有助于提升面试评价的可靠性/效度。

**外推限制：** 综述年代较早，不能推定每家中国企业都采用STAR或统一量表。

**本章落地动作：** 用JD能力维度构建3-5个行为问题和评价标准，录音自练时征得所有参与者同意。
