# SOP · 把JD转成可核验简历

适用对象：正在处理「简历：用证据争取面试机会」的人。建议先完成相应章节：[简历：用证据争取面试机会](../guides/02-resume.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：把JD转成可核验简历。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/resume-evidence-map.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 拆出JD关键词

**操作：** 对五份最想投的JD提取技能、行业、结果、协作和技术栈，把必须项优先展示。
**验收：** 一张岗位要求映射表。
**走不通：** 技能不具备时不能为了ATS塞进简历。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 重写经历为结果句

**操作：** 每段用“业务问题→本人行动→结果→证据/归因说明”改写，不写空洞职责。
**验收：** 五条可核验的项目成果句。
**走不通：** 没有可披露数字就用范围、比例或已获授权的事实。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 制作两版简历

**操作：** 为两个相近岗位调整摘要、关键词和案例顺序，不同时维护十个版本。
**验收：** 两份PDF和一份修改记录。
**走不通：** 版本混乱就保留单一事实库，所有版本从事实库引用。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 做一次招聘方视角检查

**操作：** 用30秒回答“应聘什么、最强证据是什么、是否满足硬条件”；检查日期逻辑。
**验收：** 简历勘误清单，零日期矛盾。
**走不通：** 请两位同行帮看并删除所有个人敏感信息后分享。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 整理作品集

**操作：** 为有项目展示需求的岗位做3个项目卡：问题、设计、本人职责、真实结果、复盘。
**验收：** 匿名作品集链接或PDF。
**走不通：** 涉及保密项目时展示思路方法，不上传公司素材。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 列岗位硬要求并映射本人真实项目事实。
- **现实校准：** 形成两版简历，逐句核对事实和量化数据。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `resume-evidence-map.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
