# SOP · 建立求职漏斗与内推行动

适用对象：正在处理「投递、内推与求职漏斗」的人。建议先完成相应章节：[投递、内推与求职漏斗](../guides/03-pipeline.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：建立求职漏斗与内推行动。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/pipeline-retro.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 建立30个岗位跟踪表

**操作：** 记录岗位来源、投递日期、状态、下一步、联系人、反馈与截止日期。
**验收：** 30行无重复投递记录。
**走不通：** 无法确认状态时标未回复，不标失败。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 把岗位分三级

**操作：** 按技能匹配、薪酬空间、公司可信度、发展路径分A/B/C，优先投A类。
**验收：** 10个A类目标岗位。
**走不通：** 只有少量A类时接受高潜力B类，但记下不足。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 写有事实的内推请求

**操作：** 给前同事发一段≤120字请求：目标岗位、匹配点、简历链接、是否方便；不要求对方背书不熟悉的经历。
**验收：** 3条经过个性化修改的合法联系记录。
**走不通：** 没人内推也能投官网，不花钱购买所谓保录名额。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 每周复盘漏斗

**操作：** 按投递→回复→一面→后续面试→Offer分段统计人数或岗位数，分析最薄弱环节。
**验收：** 每周一张漏斗表和单点修复动作。
**走不通：** 样本少时不对百分比做确定推断。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 防止求职诈骗

**操作：** 核对招聘主体、公司官方入口、岗位JD与要求；拒绝支付保录费、泄露验证码或提供无关证件。
**验收：** 每个高风险岗位的主体核验记录。
**走不通：** 有疑点先终止提供资料，使用平台举报或官方渠道核实。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 记录岗位、渠道、版本和每一步真实反馈。
- **现实校准：** 每周明确哪个环节掉点且只修改1-2件事。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `pipeline-retro.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
