# SOP · 安全离职与新岗位90天

适用对象：正在处理「离职交接与新工作90天」的人。建议先完成相应章节：[离职交接与新工作90天](../guides/07-exit.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：安全离职与新岗位90天。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/onboarding-90days.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 确认新岗位真实录用流程

**操作：** 核对录用主体、职位、薪酬、背景调查和入职条件，保存正式书面通知。
**验收：** Offer关键条款核对表。
**走不通：** 背景核查未完或条件未满足时谨慎做不可逆离职决定。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 制定合法合规交接清单

**操作：** 整理负责事项、关键里程碑、依赖人、文档位置，遵守原单位保密及资料处置规范。
**验收：** 经主管认可的交接记录。
**走不通：** 保密内容只交接到公司授权系统。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 准备新岗位前30天计划

**操作：** 围绕业务理解、关键人访谈、首个交付和风险沟通形成轻量计划。
**验收：** 首30天行动清单。
**走不通：** 不要在未入职前索取对方敏感业务数据。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 在第30天核对试用期标准

**操作：** 向主管确认评价指标、反馈频率、支持资源与改进方向。
**验收：** 双方确认的评估框架和下次复核日期。
**走不通：** 标准模糊时要求书面列举可观察行为。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 在第90天回看真实收益

**操作：** 核对实际收入、业务成长、强度和风险是否符合跳槽前预期。
**验收：** 90天收益与成本复盘。
**走不通：** 不达标时先求证是阶段性问题还是结构性偏差。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 明确Offer条件、合同、竞业限制和交接范围。
- **现实校准：** 完成合法交接并在30/60/90天校准评价标准。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `onboarding-90days.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
