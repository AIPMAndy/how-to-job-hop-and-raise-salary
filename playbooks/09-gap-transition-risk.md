# SOP · 处理空窗期、转行和可疑招聘

适用对象：正在处理「复杂情况：失业、转行、空窗期与风险」的人。建议先完成相应章节：[复杂情况：失业、转行、空窗期与风险](../guides/09-special.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：处理空窗期、转行和可疑招聘。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/risk-register.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 有空窗期：实话解释

**操作：** 用事实说明空窗原因、期间保持的技能、为何现在适合岗位；对不必要的私事保留边界。
**验收：** 30秒空窗解释稿，日期与简历一致。
**走不通：** 不编造自由职业项目或虚假任职。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 转行：解释可迁移能力

**操作：** 把旧行业成绩映射成新岗位需要的通用能力，补一个可展示的项目。
**验收：** 三项迁移能力与一项作品。
**走不通：** 硬技能差距明显就先选相邻岗位过渡。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 35岁以上：主打结果与适配

**操作：** 突出复杂项目判断、经验迁移、管理效率与可持续投入，不做年龄刻板推断。
**验收：** 三张有结果的资深能力卡。
**走不通：** 遇到不合理年龄限制保留信息，了解合法维权途径。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 在职保密求职

**操作：** 设置合适的联系时间、使用私人设备与邮箱，不复制前雇主商业秘密或客户资料。
**验收：** 私人求职资料夹与安全检查表。
**走不通：** 不允许招聘方索取与应聘无关的敏感内容。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 若遭遇疑似虚假招聘

**操作：** 验证招聘主体、薪酬条件和办公地址，不转账、不交押金、不共享验证码。
**验收：** 风险事实记录及必要的举报路径。
**走不通：** 暂停互动，通过官方招聘渠道或相关主管部门核实。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 按事实解释职业空窗，列可迁移技能的作品证据。
- **现实校准：** 核验招聘主体与风险，必要时用官方渠道维权。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `risk-register.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
